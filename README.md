Mehendi Booking Website

A web-based Mehendi booking website designed to help customers explore Mehendi services and make booking enquiries online.

Project Overview

The Mehendi Booking Website provides a simple and user-friendly interface for customers to view the website and submit booking requests. It also includes an admin interface for managing booking-related information.

Features

- User-friendly home page.
- Mehendi image gallery.
- Online booking interface.
- Admin dashboard.
- Booking management interface.
- Responsive website design.
- Separate CSS and JavaScript files.

Technologies Used

- HTML5
- CSS3
- JavaScript
